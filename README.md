# Jungle

Jungle 是一个实验性游戏引擎，旨在探索现代 C++ 标准（C++26）在游戏开发中的应用。项目充分利用编译期反射等新特性，构建类型安全、零开销的基础设施层。

## 文档

- [简体中文](https://pointertobios.github.io/Jungle/zhcn/)
- [English](https://pointertobios.github.io/Jungle/enus/)

## Roadmap

- [x] 基础类型系统
- [x] 测试框架
- [x] 编译期反射元编程工具
- [x] 序列化/反序列化框架
- [x] ECS 核心
- [x] 异步框架（不再开发新特性，随 ASCO 同步）
- [ ] Service 层
  - [ ] Log service
  - [ ] Display service
  - [ ] Game service
- [ ] 资源管理
- [ ] doxygen 文档生成器
- [ ] ECS 查询系统
- [ ] mimalloc 接入
